# tpm-agentic-ai

# TPM Agentic AI Journey 🤖

A collection of experiments, learnings, and practical implementations exploring how Agentic AI transforms Technical Program Management.

## About This Repository

As a Technical Program Manager leading Agentic AI programs, I'm documenting my journey of integrating AI tools into daily TPM workflows. This repository showcases generic examples and learnings from building productivity-enhancing AI agents.

**Focus Areas:**
- Meeting intelligence and automation
- Communication optimization
- Organization and task management
- Presentation and documentation generation
- Cross-functional coordination with AI assistance

## Tools & Technologies

- **Gemini**: Multi-modal AI interactions and strategic planning
- **NotebookLM**: Knowledge synthesis and research
- **Cursor**: AI-assisted development and automation
- **RAG Systems**: Internal knowledge retrieval and context-aware responses
- Custom agent frameworks for TPM workflows
